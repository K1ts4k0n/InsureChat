# 0005 — Intake 5 ฟิลด์ + AI scoping (แทนฟอร์มเต็ม/ตารางเปรียบเทียบ)

เดิม ([[docs/adr/0004]]) หน้า quote เก็บ 9 ฟิลด์ (รวมผลิตภัณฑ์/ทุน/ไฟไหม้/น้ำท่วม) แล้วแสดง **ตารางเปรียบเทียบ** ให้เลือกเอง. เราเปลี่ยนเป็น: ฟอร์ม **5 ฟิลด์ = ระบุตัวรถเท่านั้น** (ยี่ห้อ/รุ่น/CC/ปี/จังหวัด) → ค้นได้ **candidate set** (ทุกชั้น/บริษัท/ทุน ของรถ+จังหวัดนั้น) → **เข้าแชตเลย** ให้ **AI สโคป** เรื่องทุน/งบเบี้ย/ทุนไฟไหม้/น้ำท่วม แล้วกรองเหลือ "ผลิตภัณฑ์ที่ตรงที่สุด 3 แผน" ให้เลือก.

แยกหน้าที่ชัด: **ฟอร์ม = ระบุรถ** · **AI = ที่ปรึกษาเลือกความคุ้มครอง/งบ** (consultative — ตรงจุดแข็งของ LLM มากกว่าให้ลูกค้าจิ้ม dropdown ทุน/ไฟ/น้ำเอง).

## Considered Options

- **5-field intake → AI scoping (เลือก)** — ฟอร์มสั้น เร็ว; การเลือกความคุ้มครองเป็นบทสนทนา. แลกกับ: ต้องพึ่ง LLM ในขั้นเลือก (มี fallback), และย้าย logic การกรองเข้า tool.
- **คงฟอร์ม 9 ฟิลด์ + ตารางเปรียบเทียบ (เดิม)** — เลือกเองครบ ไม่พึ่ง AI แต่ลูกค้าทั่วไปไม่รู้จะใส่ทุน/ไฟ/น้ำเท่าไหร่ → ฟอร์มยาว สับสน.

## Consequences

- **Grounding (บังคับ, ต่อจาก [[docs/adr/0003]]):** AI กรองผ่าน tool `filter_packages` ที่ทำงานบน **candidate set จริง** (เก็บใน `conversationContext.candidates` จากการค้น 5 ฟิลด์) เท่านั้น — ห้ามเลือก/อ้างเบี้ย/ชื่อแผนเอง. system prompt ฉีด **สรุป candidate** (จำนวน/บริษัท/ช่วงทุน-เบี้ย/ชั้นที่มี) ให้ AI เกริ่นได้โดยไม่ต้องดัมพ์ทุกแถว.
- **จังหวัด — ตรวจแล้วกรองจริงไม่ได้:** ตั้งใจให้กรองผ่าน `ProvinSale`/`PackagePolType.ProvinId` แต่ตรวจ DB จริงพบว่า **ทุกแพคเกจ (ตามตัวรถ) เป็น `ProvinId=0` nationwide และไม่อยู่ใน ProvinSale** (HONDA CIVIC 1.8 2020 = 53 แผน, inProvinSale=0). KPN production เองก็ส่ง `provinPlate` มาแต่ไม่กรอง (response: `provinnamePackage="ไม่มีข้อมูล"`) — เป็นเหตุผลที่ KPN คอมเมนต์ filter ทิ้ง. ∴ **จังหวัดเป็นฟิลด์เก็บข้อมูล (ลง proposal) ไม่ใช่ตัวกรอง** — ไม่ทำ filter ปลอม (grounding/คปภ.).
- **ตัดทิ้งจากหน้า quote:** dropdown ผลิตภัณฑ์/ทุน/ไฟไหม้/น้ำท่วม, ตารางเปรียบเทียบ, เทียบ-4, โลโก้ในตาราง (ความคุ้มครองย้ายไปสโคปในแชต).
- **flow:** quote(5) → candidate set → chat: AI ถามทุน→งบ→ไฟ→น้ำ → `filter_packages` → shortlist 3 → เลือก → `prepare_proposal` → `/Propose` (เดิม).
- **Resilience:** direct `/chat` ที่ไม่มี candidate → เด้งไป `/quote`. LLM ล่ม → fallback แสดง candidate เป็นลิสต์กรองมือเบาๆ (ไม่ใช่ state machine เดิม ซึ่งไม่ทำ scoping).
