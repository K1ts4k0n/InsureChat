## 🔎 วิธีค้นหา (ข้อมูลครบ ไม่ตก — ค้นจาก JSON ดิบโดยตรง)
ใช้เครื่องมือ `tools/motor/query.py` กรองได้หลายเงื่อนไข (ดู [[T-Broker-โบรกเกอร์|คู่มือ]]):
```bash
python tools/motor/query.py --brand HONDA --model CIVIC --class 1 --year 2020
python tools/motor/query.py --brand TOYOTA --class 2+ --prem-max 15000 --sort prem
```
