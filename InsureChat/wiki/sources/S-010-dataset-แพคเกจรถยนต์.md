# S-010 — ชุดข้อมูลแพคเกจรถยนต์ T Broker

> **ที่มา:** `raw/ข้อมูลแพคเกจรถยนต์_Page1.json` … `_Page10.json` (export จากระบบคำนวณเบี้ย [[T-Broker-โบรกเกอร์|T Broker]]) — ~330 MB, **อ่านอย่างเดียว ห้ามแก้**

## ขนาด & ขอบเขต
- **330,408 แพคเกจ** แบ่ง 10 ไฟล์ (pageSize 35,000) · ปีรถ 1994–2026
- 4 บริษัท · 39 ยี่ห้อ · ชั้น 1/2+/3+/3 · เกือบทั้งหมดซ่อมอู่ (ห้าง 8 รายการ) · ช่องทาง Corporate

## โครงสร้างข้อมูล (schema 17 ฟิลด์ต่อ record)
| ฟิลด์ | ความหมาย |
|-------|----------|
| `packageName`, `polTypeID` | ชื่อ/ประเภทแพคเกจ (ใช้แยกชั้น 1/2+/3+/3) |
| `insureID` | บริษัทประกัน |
| `carBrandName`, `carModelName`, `ccmax`, `year` | ยี่ห้อ/รุ่น/ซีซี/ปีรถ |
| `sumInsureMax` | ทุนประกัน (50,000–10,000,000) |
| `premNet`, `premStm` | เบี้ยสุทธิ / เบี้ยรวมอากร (2,700–94,113) |
| `renovType` | ประเภทซ่อม (อู่/ห้าง) |
| `rowKey`, `docNo`, `brokerPayID`, `premType`, `comeInCode`, `provinName` | คีย์/เมตา |

## วิธีจัดเก็บในวิกิ (ข้อมูลครบ ไม่ตก)
- JSON ดิบ = source of truth (ไม่ duplicate ลง markdown)
- **สรุป/หมวดหมู่** → [[แพคเกจรถยนต์-T-Broker]] (สร้างอัตโนมัติด้วย `tools/motor/build_catalog.py`)
- **ค้นหา/กรอง** → `tools/motor/query.py` (อ่าน JSON ดิบโดยตรง → ข้อมูลทั้ง 330k เข้าถึงได้เสมอ)

## ⚠️ ข้อควรระวัง (จรรยาบรรณ)
เบี้ยในชุดนี้เป็น **package rate** ที่ export มา ณ วันที่ — **ยืนยันเบี้ย/เงื่อนไขล่าสุดในระบบ T Broker ก่อนเสนอลูกค้าจริง** ([[คปภ-การกำกับและจรรยาบรรณตัวแทน]])
