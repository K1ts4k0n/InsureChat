## 🔎 คู่มือค้นแพคเกจรถ — `tools/motor/query.py`
ค้นจากข้อมูลดิบ 330,408 แพคเกจโดยตรง (ดูคลัง [[แพคเกจรถยนต์-T-Broker]])

**ตัวกรอง:** `--brand` `--model` `--class` (1/2+/3+/2/3) `--insurer` (ธนชาต/เมืองไทย/วิริยะ/โตเกียว) `--year` `--year-min` `--year-max` `--sum-min` `--sum-max` `--prem-min` `--prem-max` `--renov` (อู่/ห้าง) `--sort` (prem/sum/year) `--limit` `--json`

```bash
# Honda Civic ชั้น 1 ปี 2020 (เรียงเบี้ยถูกสุดก่อน)
python tools/motor/query.py --brand HONDA --model CIVIC --class 1 --year 2020

# Toyota ชั้น 2+ เบี้ยไม่เกิน 12,000 ของธนชาต
python tools/motor/query.py --brand TOYOTA --class 2+ --prem-max 12000 --insurer ธนชาต

# รถหรู ทุนเกิน 1 ล้าน เทียบเบี้ยข้ามบริษัท
python tools/motor/query.py --brand BENZ --sum-min 1000000 --sort prem --limit 30
```
> เมื่อผู้ใช้ถามทำนอง "หาประกันรถ … เบี้ยเท่าไหร่" → รัน `query.py` แล้วสรุปผล + เทียบตัวเลือกด้วย [[เปรียบเทียบแผน-จับคู่-need]] **อย่าเดาเบี้ยเอง**
