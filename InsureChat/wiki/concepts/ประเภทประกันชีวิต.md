# ประเภทประกันชีวิต

ประกันชีวิตในไทยแบ่งเป็น **4 แบบหลัก** + แบบ **Unit Linked** (มีส่วนลงทุน) — รู้จักให้แม่นเพื่อจับคู่กับ Need ของลูกค้า (ดู [[spin-selling-การขายแบบที่ปรึกษา]]) (ที่มา: [[S-004]])

| แบบ | จุดเด่น | เหมาะกับ Need |
|-----|---------|----------------|
| **ตลอดชีพ (Whole Life)** | คุ้มครองยาวถึงอายุสูง เบี้ยไม่สูง มีมูลค่าเวนคืน ทำง่าย ยืดหยุ่น | สร้างมรดก/หลักประกันให้ครอบครัว คุ้มครองตลอดชีวิต |
| **ชั่วระยะเวลา (Term)** | เบี้ยถูกที่สุด คุ้มครองสูงในงบจำกัด ไม่มีเงินคืน | คุ้มครองหนี้สิน/ภาระช่วงสร้างตัว (ผ่อนบ้าน/รถ ลูกยังเล็ก) |
| **สะสมทรัพย์ (Endowment)** | ออม + คุ้มครอง มีเงินคืนเป็นงวด/ครบสัญญา ลดหย่อนภาษีได้ | คนชอบความแน่นอน อยากออมมีวินัย + คุ้มครอง |
| **บำนาญ (Annuity)** | รับเงินบำนาญหลังเกษียณ ลดหย่อนภาษีได้สูง | วางแผนเกษียณ มีรายได้ประจำยามแก่ |
| **Unit Linked** | ยืดหยุ่นสูง ปรับความคุ้มครอง/ลงทุนได้ มีโอกาสผลตอบแทนจากการลงทุน | วางแผนการเงินระยะยาว รับความเสี่ยงได้ |

## ⚠️ ข้อควรระวังเรื่อง Unit Linked
ผลตอบแทนของส่วนลงทุน **ไม่การันตี** ขึ้นกับผลกองทุน — ต้องเปิดเผยความเสี่ยงและค่าธรรมเนียมตามจริงเสมอ (ดู [[คปภ-การกำกับและจรรยาบรรณตัวแทน]]) ห้ามขายโดยชูแต่ผลตอบแทนสูง

## ประเด็นใช้ขาย
- อย่าเริ่มจาก "แบบประกัน" → เริ่มจาก **Need ของลูกค้า** แล้วค่อยจับคู่แบบ
- ลดหย่อนภาษี (สะสมทรัพย์/บำนาญ) เป็น hook ที่ดีกับลูกค้ามนุษย์เงินเดือน/ฐานภาษีสูง
- เชื่อมไปหน้า [[products/]] เมื่อมีแผนจริงของบริษัทที่ขาย
