# ประกันกลุ่ม (สวัสดิการพนักงาน)

คุ้มครองคนทั้งกลุ่มภายใต้กรมธรรม์เดียว — **ดีลใหญ่ เบี้ยรวมสูง ต่ออายุทุกปี** ลูกค้าหลักคือ **เจ้าของธุรกิจ/HR** (ที่มา: [[S-008]])

## ความคุ้มครองที่ประกอบได้ (เลือกผสม)
| โมดูล | ย่อ | คุ้มครอง |
|-------|-----|----------|
| ชีวิตกลุ่ม | GL | เสียชีวิต (ทุกกรณี) |
| อุบัติเหตุกลุ่ม | GPA | เสียชีวิต/ทุพพลภาพจากอุบัติเหตุ ([[ประกันอุบัติเหตุส่วนบุคคล-PA]]) |
| สุขภาพผู้ป่วยใน | GH/IPD | ค่าห้อง ค่ารักษา ผ่าตัด |
| ผู้ป่วยนอก | OPD | ค่ารักษาไม่นอน รพ. |
| ทุพพลภาพ/ชดเชยรายได้ | GTD | สูญเสียความสามารถทำงาน |
| โรคร้ายแรง | GCI | เงินก้อนเมื่อตรวจพบโรคร้าย |

## จุดขายต่อเจ้าของธุรกิจ
1. **ดึงดูด + รักษาพนักงาน** (สวัสดิการแข่งกับตลาดแรงงาน)
2. **เบี้ยเป็นค่าใช้จ่ายบริษัท → ลดหย่อนภาษีนิติบุคคล**
3. **เงื่อนไขรับประกันง่าย** มัก**ไม่ต้องตรวจสุขภาพ**, เบี้ย**ถูกกว่ารายบุคคล**
4. เริ่มได้ตั้งแต่พนักงาน **3–5 คนขึ้นไป** (แล้วแต่บริษัท)

## จับคู่ Need (ดู [[เปรียบเทียบแผน-จับคู่-need]] + [[spin-selling-การขายแบบที่ปรึกษา]])
- SME เล็ก งบจำกัด → เริ่ม GPA + GL (เบี้ยต่ำ) แล้วค่อยเพิ่มสุขภาพ
- บริษัทแย่งคนเก่ง → ชู IPD+OPD+CI เป็นจุดขายสวัสดิการ

## ข้อควรเปิดเผย ([[คปภ-การกำกับและจรรยาบรรณตัวแทน]])
- จำนวนขั้นต่ำ, อัตราเข้าร่วม (participation), เงื่อนไขสภาพที่เป็นมาก่อน, การปรับเบี้ยตามประวัติเคลม (loss ratio) ตอนต่ออายุ
