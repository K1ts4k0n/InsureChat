# เปรียบเทียบแผน & จับคู่ Need ลูกค้า

> 🎯 **จุดเน้นหลักของผู้ใช้** — ขายวินาศภัยด้วย "ความรู้ผลิตภัณฑ์ + การเปรียบเทียบที่ชัด" ทำให้ลูกค้าตัดสินใจเองอย่างมั่นใจ

## หลักคิด: เปรียบเทียบเพื่อ "ช่วยเลือก" ไม่ใช่ "อวดของ"
อย่ากองสเปกทั้งหมด → คัดเฉพาะ **3–4 มิติที่ลูกค้าแคร์จริง** แล้วจัดเป็นตารางสแกนง่าย

## ขั้นตอน 4 สเต็ป
1. **ขุด Need ก่อนเปรียบเทียบ** ([[spin-selling-การขายแบบที่ปรึกษา]]) — งบ, ความเสี่ยงที่กลัวที่สุด, ของที่จะปกป้อง
2. **คัดมิติเปรียบเทียบ** ให้ตรง Need (เช่น รถ: "คุ้มรถหายไหม / เบี้ย / คุ้มชนเองไหม")
3. **ทำตารางเปรียบเทียบ** (ใช้ [[templates/comparison|เทมเพลต comparison]]) — ติ๊ก ✅/❌ + ไฮไลต์ช่องที่ตรง Need
4. **แนะนำตัวเลือก + เหตุผล** เปลี่ยนเป็นการปิด ([[เทคนิคปิดการขาย]] — assumptive/choice close)

## ตารางจับคู่ "Need → แผน" (สายวินาศภัย)
| ลูกค้าพูด/สถานการณ์ | Need จริง | แผนที่ตรง |
|----------------------|-----------|-----------|
| "รถใหม่ป้ายแดง ผ่อนอยู่" | กลัวเสียหายหนัก/รถหาย | [[ประกันรถยนต์\|ชั้น 1]] |
| "รถ 7 ปี อยากประหยัดแต่ยังอุ่นใจ" | คุ้มชน + กลัวรถหาย/น้ำท่วม | [[ประกันรถยนต์\|ชั้น 2+]] |
| "ขับน้อย รถเก่า งบน้อย" | คุ้มคู่กรณีพอ | [[ประกันรถยนต์\|ชั้น 3]] + พ.ร.บ. |
| "เพิ่งซื้อบ้าน/ผ่อนกับแบงก์" | คุ้มไฟไหม้/ทรัพย์สิน | [[ประกันอัคคีภัย-และที่อยู่อาศัย]] |
| "อยากได้อะไรเบี้ยถูก ๆ ไว้ก่อน" | คุ้มอุบัติเหตุ ปิดง่าย | [[ประกันอุบัติเหตุส่วนบุคคล-PA]] |
| "ผมเป็นเจ้าของบริษัท มีพนักงาน 20 คน" | สวัสดิการ + ลดหย่อนภาษีนิติบุคคล | [[ประกันกลุ่ม-สวัสดิการพนักงาน]] |

## เทคนิคนำเสนอตาราง
- **ไฮไลต์ช่องชนะ** ของแผนที่แนะนำ ให้ตาลูกค้าวิ่งไปถูกจุด
- ใช้กฎ **"good-better-best"** 3 ตัวเลือก → ลูกค้ามักเลือกตัวกลาง (anchoring)
- จบด้วย *"จากที่คุยมา แผนนี้ตอบโจทย์คุณที่สุดเพราะ... จะเริ่มเล่มนี้เลยไหมครับ"*

## ห้ามลืม (จรรยาบรรณ)
เปรียบเทียบ**ตามจริง** ไม่บิดเบือนข้อด้อยของแผนที่อยากขาย เปิดเผยข้อยกเว้นครบ ([[คปภ-การกำกับและจรรยาบรรณตัวแทน]])
