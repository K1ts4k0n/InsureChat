## ขั้นตอนย่อ (quick reference)

### Ingest
1. อ่านไฟล์ใน `raw/` → 2. คุย takeaways สั้น ๆ → 3. สร้าง `wiki/sources/S-xxx-*.md`
→ 4. อัปเดตหน้า concepts/products/playbooks/clients ที่เกี่ยว → 5. เช็กความขัดแย้ง
→ 6. อัปเดต `index.md` → 7. append `log.md` → 8. รายงานผล + เสนอ next step

### Query
1. อ่าน `index.md` หาหน้าเกี่ยว → 2. เจาะอ่านหน้านั้น → 3. ตอบพร้อมอ้างอิง `[[...]]`
→ 4. ถ้ามีค่าใช้ซ้ำได้ เสนอ file-back เป็นหน้าใหม่ + อัปเดต index/log

### Lint
ไล่หา: ขัดแย้ง / ตกยุค / orphan / แนวคิดไร้หน้า / ลิงก์ขาด / ช่องว่างข้อมูล
→ เสนอคำถาม+แหล่งที่ควรหาเพิ่ม → append `log.md`

### Client update
สร้าง/แก้ `wiki/clients/*.md` ตาม pipeline §5.2 (lead→...→closed) บันทึกการพบลงวันที่
→ อัปเดต index/log (action = `client-update`)

## หลักการที่ต้องไม่ลืม
- **เคารพ raw/ = อ่านอย่างเดียว** ไม่แก้ไฟล์ต้นทาง
- **เชื่อมลิงก์ liberally** + **อ้างอิงแหล่งทุกข้อเท็จจริง**
- **ทำให้วิกิรวยขึ้นทุกครั้ง** (ingest หรือ query ก็ตาม)
- **ยึดจรรยาบรรณ** (CLAUDE.md §11) และ **ความเป็นส่วนตัวลูกค้า** (§12)
- ปิดท้ายด้วยเช็กลิสต์ Definition of Done (§13)
