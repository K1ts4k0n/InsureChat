# 🏠 ภาพรวม InsureChat Wiki

วิกินี้คือ **สมองที่สอง (Second Brain & AI Knowledge Base)** ของระบบ InsureChat — สะสมความรู้การขาย กฎหมาย ผลิตภัณฑ์ และข้อมูลลูกค้า เพื่อให้ AI และตัวแทนสามารถค้นหาและตอบลูกค้าได้อย่างแม่นยำที่สุดตามมาตรฐานวิชาชีพ

- **คลังแพคเกจรถจริง 330,408 รายการ** → [[แพคเกจรถยนต์-T-Broker]] ผ่าน [[T-Broker-โบรกเกอร์]] — ค้นด้วย `tools/motor/query.py`
