# คปภ. — การกำกับและจรรยาบรรณตัวแทนและนายหน้าประกันภัย

สำนักงาน **คปภ. (OIC)** กำกับการประกอบธุรกิจประกันภัยตาม พ.ร.บ. ประกันวินาศภัย และ พ.ร.บ. ประกันชีวิต พ.ศ. 2535 (แก้ไขเพิ่มเติม) รวมถึงหลักเกณฑ์การเสนอขายของคนกลางประกันภัย (ที่มา: [[S-005]], [[S-011]], [[S-012]])
ดูฉบับสมบูรณ์ที่: [[06-broker-regulations-and-ethics]]

> นี่คือ **เส้นที่ห้ามข้าม (Strict Red Line)** — อ้างอิงในทุกบทขายและการตอบคำถามของ AI

---

## 1. หลักจรรยาบรรณ 6 ประการที่ต้องยึดมั่น
1. **ความซื่อสัตย์สุจริต (Integrity):** ปฏิบัติหน้าที่ด้วยความโปร่งใส ยุติธรรม ไม่แสวงหาผลประโยชน์มิชอบ
2. **มาตรฐานวิชาชีพ (Competence):** ให้บริการด้วยความรู้ ความเชี่ยวชาญ และความระมัดระวังรอบคอบ
3. **การรักษาความลับ (Confidentiality):** รักษาความลับข้อมูลส่วนบุคคลและข้อมูลทางการเงินของลูกค้า
4. **เปิดเผยข้อมูลครบถ้วน (Full Disclosure):** แจ้งเงื่อนไข ความคุ้มครอง ข้อยกเว้น และเบี้ยประกันภัยตามจริง **ห้ามปิดบังหรือบิดเบือน**
5. **ห้ามชักชวนให้ยกเลิกกรมธรรม์เดิม (Prohibition of Twisting/Churning):** ห้ามแนะนำให้ลูกค้ายกเลิกกรมธรรม์เดิมเพื่อมาซื้อฉบับใหม่ที่ทำให้ลูกค้าเสียสิทธิประโยชน์
6. **พัฒนาตนเองต่อเนื่อง (Continuous Learning):** ติดตามกฎระเบียบและเงื่อนไขกรมธรรม์ใหม่ๆ เสมอ

---

## 2. ข้อห้ามสำคัญตามกฎหมาย พ.ร.บ. ประกันวินาศภัย
- **ต้องมีใบอนุญาต:** ผู้ไม่มีใบอนุญาตตัวแทนหรือนายหน้า ห้ามชักชวนหรือชี้ช่องทำประกันภัย
- **ห้ามเป็นทั้งตัวแทนและนายหน้าพร้อมกัน:** บุคคลคนเดียวกันเป็นทั้งตัวแทนและนายหน้าประกันวินาศภัยในเวลาเดียวกันไม่ได้
- **การรับเงินค่าเบี้ยประกันภัย:** ต้องมี **หนังสือมอบอำนาจเป็นลายลักษณ์อักษรจากบริษัทประกันภัย** จึงจะรับเบี้ยได้ และต้องออกใบเสร็จรับเงินตามแบบที่กำหนดทันที
- **ห้าม Mis-selling:** ห้ามเสนอขายแผนที่ไม่ตรงกับความต้องการจริง ห้ามบอกข้อมูลเท็จ หรือการันตีสิ่งที่ไม่ตรงตามกรมธรรม์
- **ห้ามกดดัน/สร้างความกลัว:** การปิดการขายต้องตั้งอยู่บนการวิเคราะห์ความจำเป็น (Need-based) อย่างมีจรรยาบรรณ

---

## 3. กองทุนประกันวินาศภัย
- คุ้มครองเจ้าหนี้ตามสัญญาประกันภัยกรณีบริษัทประกันภัยถูกเพิกถอนใบอนุญาตหรือล้มละลาย
- จ่ายเงินช่วยเหลือสูงสุด **ไม่เกิน 1,000,000 บาท ต่อราย**
