# ประกันอุบัติเหตุส่วนบุคคล (PA)

ประกันสาย[[ประเภทประกันวินาศภัย|วินาศภัย]] ที่คุ้มครองเฉพาะ **อุบัติเหตุ** เบี้ยต่ำ เงื่อนไขง่าย — เป็น **entry product ที่ปิดง่ายและใช้เปิดประตูลูกค้า** (ที่มา: [[S-008]])

## ความคุ้มครองหลัก
- **อบ.1:** เสียชีวิต/สูญเสียอวัยวะ/ทุพพลภาพถาวร จากอุบัติเหตุ (จ่ายเงินก้อน)
- **อบ.2:** เพิ่มสูญเสียนิ้ว/การได้ยิน/การพูด
- **ค่ารักษาพยาบาลจากอุบัติเหตุ** (ต่อครั้ง), **ชดเชยรายได้ระหว่างรักษา** (option)
- ความคุ้มครองเสริม: ขับขี่/โดยสารจักรยานยนต์, ฆาตกรรม/ลอบทำร้าย

## จุดขาย / จับคู่ Need
- **เบี้ยต่ำมาก** (หลักร้อย–พันบาท/ปี) → ใช้ [[เทคนิคปิดการขาย|price anchoring]] ได้ผลดี
- เหมาะ **ทุกกลุ่ม**: เด็ก/นักเรียน, วัยทำงาน, ผู้สูงวัย, อาชีพเสี่ยง
- ต่อยอดเป็น [[ประกันกลุ่ม-สวัสดิการพนักงาน|PA กลุ่ม]] สำหรับองค์กร

## ข้อควรเปิดเผย ([[คปภ-การกำกับและจรรยาบรรณตัวแทน]])
- คุ้มเฉพาะ "อุบัติเหตุ" ไม่รวมเจ็บป่วย, ชั้นอาชีพมีผลต่อเบี้ย/การรับประกัน, ข้อยกเว้น (แข่งกีฬาเสี่ยง, สารเสพติด ฯลฯ)
