# คู่มือประกันอัคคีภัยและความเสี่ยงภัยทรัพย์สิน (Fire & Property Insurance Master Guide)

> **แหล่งข้อมูลอ้างอิง:**
> - คู่มือเตรียมสอบนายหน้าประกันวินาศภัย (หมวดประกันอัคคีภัย) [[S-011]]
> - คู่มือประกันวินาศภัยไทย สมาคมประกันวินาศภัยไทย (TGIA) บทที่ 18 [[S-012]]
> - พิกัดอัตราเบี้ยประกันอัคคีภัย สำนักงาน คปภ.

---

## 1. ประเภทของกรมธรรม์ประกันอัคคีภัย

การประกันอัคคีภัยในประเทศไทยแบ่งออกเป็น 3 รูปแบบหลักตามลักษณะของสถานที่และการใช้งาน:

```
  ┌────────────────────────────────────────────────────────┐
  │              ประเภทประกันอัคคีภัยหลัก                  │
  ├───────────────────┬────────────────────┬───────────────┤
  │ 1. อัคคีภัยมาตรฐาน│ 2. อัคคีภัยที่อยู่  │ 3. สรรพภัย    │
  │    (ธุรกิจ/โรงงาน)│    อาศัย (บ้าน/คอนโด)│ (IAR - รายใหญ่)│
  └───────────────────┴────────────────────┴───────────────┘
```

### 1.1 ประกันอัคคีภัยมาตรฐาน (Standard Fire Policy)
- **กลุ่มเป้าหมาย:** โรงงานอุตสาหกรรม, อาคารพาณิชย์, ร้านค้า, สำนักงาน, คลังสินค้า
- **ระยะเวลาความคุ้มครอง:** สูงสุด **ไม่เกิน 3 ปี** (เวลาเริ่มความคุ้มครอง **16.00 น.** และสิ้นสุดเวลา **16.00 น.**)
- **3 ความคุ้มครองพื้นฐานตามมาตรฐาน (Basic Perils):**
  1. **ไฟไหม้ (Fire)**
  2. **ฟ้าผ่า (Lightning)**
  3. **การระเบิดของแก๊ส** ที่ใช้สำหรับทำความร้อนหรือแสงสว่างเพื่อการอยู่อาศัยเท่านั้น
- *ภัยเพิ่มเติมที่ต้องซื้อเพิ่ม:* ภัยลมพายุ, ภัยน้ำท่วม, ภัยแผ่นดินไหว, ภัยระเบิดทั่วไป, ภัยยวดยานพาหนะ, ภัยอากาศยาน, ภัยระอุ (Spontaneous Combustion เหมาะกับโรงงานแป้งมัน/น้ำตาล/พืชผลเกษตร)

---

### 1.2 ประกันอัคคีภัยสำหรับที่อยู่อาศัย (Residential Fire Policy)
- **กลุ่มเป้าหมาย:** บ้านเดี่ยว, ทาวน์เฮาส์, อาคารพาณิชย์ที่ใช้พักอาศัย, ห้องชุดคอนโดมิเนียม
- **ระยะเวลาความคุ้มครอง:** สามารถซื้อระยะยาวได้สูงสุดถึง **30 ปี** (นิยมทำควบกับสินเชื่อกู้ซื้อบ้าน)
- **ทรัพย์สินที่คุ้มครอง:** สิ่งปลูกสร้าง (ไม่รวมรากฐาน), ทรัพย์สินภายในบ้าน, เฟอร์นิเจอร์, เครื่องใช้ไฟฟ้า
- **6 ภัยพื้นฐานมาตรฐาน:**
  1. ไฟไหม้ (รวมถึงไฟป่า)
  2. ฟ้าผ่า (คุ้มครองรวมถึงเครื่องใช้ไฟฟ้าที่เสียหายจากฟ้าผ่า)
  3. ภัยระเบิดทุกชนิด
  4. ภัยจากยานพาหนะ หรือช้าง ม้า วัว ควาย (ที่มิใช่ของผู้เอาประกันภัย)
  5. ภัยจากอากาศยาน หรือวัตถุที่ตกจากอากาศยาน
  6. ภัยเนื่องจากน้ำ (จากการรั่วไหลของท่อน้ำ ถังน้ำ รางน้ำฝน แต่ **ไม่รวมน้ำท่วม**)
- **4 ภัยธรรมชาติเพิ่มเติม (คปภ. กำหนดให้ขยายความคุ้มครองอัตโนมัติ):**
  1. ภัยลมพายุ
  2. ภัยน้ำท่วม
  3. ภัยแผ่นดินไหว ภูเขาไฟระเบิด หรือคลื่นใต้น้ำ หรือสึนามิ
  4. ภัยลูกเห็บ
  - *วงเงินคุ้มครองภัยธรรมชาติ:* ชดใช้ตามจริง รวมกันทุกภัย **ไม่เกิน 20,000 บาทต่อปี** (หรือสามารถจ่ายเบี้ยเพิ่มเพื่อขยายวงเงินทุนประกันตามที่ต้องการได้)

---

### 1.3 ประกันภัยความเสี่ยงภัยทรัพย์สิน (Industrial All Risks - IAR)
- **กลุ่มเป้าหมาย:** โรงงานขนาดใหญ่, โรงแรม, ศูนย์การค้า, นิคมอุตสาหกรรม (ทุนประกันตั้งแต่ 50 ล้านบาทขึ้นไป)
- **ลักษณะความคุ้มครอง:** เป็นการคุ้มครองแบบ **สรรพภัย (All Risks Basis)** หมายถึง *คุ้มครองอุบัติเหตุและความเสียหายต่อทรัพย์สินทุกกรณี เว้นแต่จะระบุไว้เป็นข้อยกเว้นอย่างชัดเจนในกรมธรรม์*
- ให้ความคุ้มครองกว้างกว่ากรมธรรม์อัคคีภัยแบบระบุภัย (Named Perils) ครอบคลุมทั้งไฟไหม้ ระเบิด ลมพายุ น้ำท่วม เครื่องจักรแตกหัก การชน และอุบัติเหตุภายนอกอื่นๆ

## 2. วิธีการกำหนดจำนวนเงินเอาประกันภัย (Sum Insured Valuation)

การตั้งทุนประกันภัยอย่างถูกต้องมีความสำคัญสูงสุดเพื่อป้องกันปัญหาการทำประกันภัยต่ำกว่ามูลค่า (Under-Insurance):

1. **Actual Cash Value (ACV) — ราคาที่แท้จริงหักค่าเสื่อมราคา:**
   $$\text{ACV} = \text{มูลค่าสร้างทดแทนใหม่ ณ ปัจจุบัน} - \text{ค่าเสื่อมราคาตามอายุการใช้งาน}$$
   ใช้เป็นเกณฑ์มาตรฐานของกรมธรรม์ทั่วไป
2. **Replacement Cost Value (RCV) — มูลค่าทดแทนของใหม่:**
   ชดใช้ตามราคาสร้างใหม่หรือซื้อใหม่ในปัจจุบัน โดย **ไม่มีการหักค่าเสื่อมราคา** ทำให้ผู้เอาประกันสามารถสร้างบ้านใหม่หรือซื้อเครื่องจักรใหม่ทดแทนได้ทันที
3. **Agreed Value — มูลค่าที่ตกลงกันไว้:**
   ใช้สำหรับทรัพย์สินที่ไม่สามารถคำนวณมูลค่าในตลาดได้อย่างชัดเจน เช่น โบราณวัตถุ ศิลปวัตถุ ภาพวาด โดยต้องมีเอกสารการประเมินราคาโดยผู้เชี่ยวชาญแนบ

## 3. การประกันอัคคีภัยแบบกระแสรายวัน (Stock Declaration Policy)

เหมาะสำหรับธุรกิจที่มี **สต๊อกสินค้าหรือวัตถุดิบที่มีความเคลื่อนไหวเข้า-ออกตลอดเวลา** และมีมูลค่าผันผวนสูงในแต่ละช่วงของปี (เช่น โกดังข้าว โรงงานสินค้าอุปโภคบริโภค):

- **หลักการดำเนินงาน:**
  1. ผู้เอาประกันภัยกำหนด **"มูลค่าสูงสุดของสต๊อกที่คาดการณ์ไว้ในปีนั้น"** เพื่อใช้เป็นจำนวนเงินจำกัดความรับผิดสูงสุด
  2. บริษัทประกันภัยจะเรียกเก็บ **เบี้ยประกันภัยล่วงหน้า 75%** ของมูลค่าสูงสุดที่คาดการณ์
  3. ผู้เอาประกันภัยมีหน้าที่ส่งรายงานสรุปยอดมูลค่าสต๊อกสินค้าจริงทุกสิ้นเดือนให้บริษัทประกันภัยทราบ
  4. สิ้นปี จะนำมูลค่าสต๊อกจริงทั้ง 12 เดือนมาคำนวณหาค่าเฉลี่ยรายเดือน เพื่อคิดเบี้ยประกันภัยที่แท้จริง
  5. **เงื่อนไขการคืนเบี้ย:** หากเบี้ยประกันภัยแท้จริงต่ำกว่าเบี้ยที่เก็บล่วงหน้า บริษัทจะคืนเงินส่วนต่างให้ แต่ **มีเงื่อนไขว่าจะคืนเงินได้ไม่เกิน 50% ของเบี้ยประกันภัยที่เก็บล่วงหน้าไปแล้ว**

## 4. ชั้นของสิ่งปลูกสร้างและปัจจัยกำหนดเบี้ยประกันภัย (Building Classes)

อัตราเบี้ยประกันอัคคีภัยขึ้นอยู่กับความยากง่ายในการติดไฟของวัสดุที่ใช้ก่อสร้าง แบ่งเป็น 3 ชั้น:

| ชั้นสิ่งปลูกสร้าง | ลักษณะโครงสร้างและผนัง | สัดส่วนคอนกรีต | ระดับความเสี่ยงและอัตราเบี้ย |
|:----------------:|:---------------------|:--------------:|:--------------------------:|
| **ชั้น 1 (ตึกล้วน)** | โครงสร้างเสา คาน และผนังทำด้วยคอนกรีต อิฐ หิน หรือวัสดุทนไฟ | มากกว่า 80% | ความเสี่ยงต่ำสุด $\rightarrow$ **เบี้ยถูกที่สุด** |
| **ชั้น 2 (ครึ่งตึกครึ่งไม้)** | ชั้นล่างเป็นคอนกรีต ชั้นบนเป็นไม้ หรือผนังมีไม้ผสม | 50% – 80% | ความเสี่ยงปานกลาง $\rightarrow$ **เบี้ยระดับกลาง** |
| **ชั้น 3 (ไม้ล้วน)** | โครงสร้างและผนังทำด้วยไม้ทั้งหมด | น้อยกว่า 50% | ความเสี่ยงสูงสุด $\rightarrow$ **เบี้ยแพงที่สุด** |

### ปัจจัยอื่นที่มีผลต่อเบี้ยประกันอัคคีภัย:
- **สถานที่ตั้งและการเข้าถึง:** ความกว้างของถนน, ระยะห่างจากสถานีดับเพลิง, ความพร้อมของหัวรับน้ำดับเพลิง
- **ความสูงของอาคาร:** อาคารที่มีความสูงเกิน **7 ชั้น** จะมีการคิดเบี้ยประกันภัยเพิ่มตามสัดส่วนความสูง
- **การใช้ประโยชน์ของอาคาร:** ที่พักอาศัยจะเบี้ยถูกกว่าร้านอาหาร โรงงานเฟอร์นิเจอร์ หรือโรงเก็บสารเคมี
- **ส่วนลดอุปกรณ์ดับเพลิง (Fire Extinguishing Appliances Discount):**
  - ได้รับส่วนลดตั้งแต่ **7.5% จนถึง 50%** ของเบี้ยประกันภัย
  - อุปกรณ์ดับเพลิงที่ได้รับส่วนลดสูงสุด คือ **"ระบบท่อพรมน้ำดับเพลิงอัตโนมัติ (Automatic Sprinkler System)"**

## 5. ทรัพย์สินที่จัดเป็นข้อยกเว้นไม่คุ้มครองในประกันอัคคีภัย

ตามเงื่อนไขกรมธรรม์ประกันอัคคีภัยมาตรฐาน จะไม่คุ้มครองทรัพย์สินดังต่อไปนี้ (เว้นแต่จะระบุในตารางคุ้มครองเป็นพิเศษ):
1. สินค้าที่อยู่ในการดูแลรักษาของผู้เอาประกันภัยในฐานะ **"ผู้รับฝากทรัพย์"**
2. **เงินแท่ง, เงินรูปพรรณ, ทองคำแท่ง, ทองรูปพรรณ, อัญมณี, เพชรพลอย**
3. **โบราณวัตถุ หรือศิลปวัตถุ** ในส่วนของมูลค่าความเสียหายที่เกินกว่า **10,000 บาท**
4. ต้นฉบับหรือสำเนาเอกสาร, แบบแปลน, แผนผัง, ภาพเขียน, พิมพ์เขียว, หลักประกันหนี้สิน, สมุดบัญชี
5. **เงินตรา, ธนบัตร, เช็ค, พันธบัตร, ไปรษณียากร, อากรแสตมป์**
6. ไดนาโม, หม้อแปลงไฟฟ้า, มอเตอร์, อุปกรณ์อิเล็กทรอนิกส์ หรือเครื่องใช้ไฟฟ้า ที่เสียหายอันเนื่องมาจาก **การเดินเครื่องเกินกำลัง, ไฟฟ้าลัดวงจร หรือการใช้กระแสไฟฟ้าเกินกำลัง** *(บริษัทจะไม่คุ้มครองเฉพาะเครื่องที่เกิดเหตุ แต่หากมีไฟลุกลามไหม้ไปยังทรัพย์สินอื่น จะคุ้มครองทรัพย์สินอื่นนั้น)*
7. วัตถุระเบิด

## 6. หลักการชดใช้กรณีทำประกันภัยต่ำกว่ามูลค่า (Average Clause in Fire Insurance)

> [!CAUTION]
> **สูตรการคิดค่าสินไหมกรณีทำประกันต่ำกว่ามูลค่า (Under-Insurance):**
> $$\text{เงินสินไหมทดแทน} = \left( \frac{\text{ทุนประกันอัคคีภัย}}{\text{มูลค่าที่แท้จริงของทรัพย์สิน}} \right) \times \text{มูลค่าความเสียหายจริง}$$

- **กฎยกเว้นพิเศษสำหรับที่อยู่อาศัย (80% Condition of Average):**
  - หากเป็น **"กรมธรรม์ประกันอัคคีภัยสำหรับที่อยู่อาศัย"** และผู้เอาประกันภัยทำทุนประกันไว้ **ไม่ต่ำกว่า 80% ของมูลค่าที่แท้จริงของตัวบ้าน** (ไม่รวมที่ดิน)
  - เมื่อเกิดไฟไหม้เสียหายบางส่วน บริษัทประกันภัยจะ **ยกเว้นเงื่อนไขเฉลี่ย** และจ่ายค่าสินไหมตามความเสียหายจริง 100% (สูงสุดไม่เกินทุนประกัน)
  - *ข้อแนะนำสำหรับตัวแทน/นายหน้า:* ให้แนะนำลูกค้าทำประกันภัยบ้านที่อยู่อาศัยอย่างน้อย 80-100% ของราคาประเมินค่าก่อสร้างใหม่เสมอ เพื่อหลีกเลี่ยงการถูกหักลดหย่อนสินไหม
