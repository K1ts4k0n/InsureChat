# คำถามลูกค้าและคีย์เวิร์ดตามประเภทประกันภัย

ใช้สำหรับจับเจตนาของลูกค้าและตอบโดยยึดความคุ้มครองในกรมธรรม์จริงเสมอ ไม่เดาเบี้ย วงเงิน หรือข้อยกเว้นของแผนที่ยังไม่ได้ตรวจสอบ

## 1. คำถามเปิดบทสนทนาที่พบบ่อย

| ลูกค้ามักพิมพ์ | เจตนา | แนวตอบ/คำถามต่อ |
|---|---|---|
| ประกันอะไรดี, เลือกชั้นไหนดี, เอาแบบคุ้ม | ต้องการคำแนะนำ | ถามวัตถุประสงค์ งบ และความเสี่ยงหลักก่อน |
| เบี้ยเท่าไร, ถูกสุด, ผ่อนได้ไหม | งบประมาณ | รถยนต์: ค้นจากข้อมูลรถและแผนจริง; ผลิตภัณฑ์อื่น: เก็บข้อมูลเพื่อขอใบเสนอราคา |
| คุ้มครองอะไร, เคลมได้ไหม, ยกเว้นอะไร | ขอบเขตความคุ้มครอง | อธิบายตามประเภท และย้ำให้ตรวจตาราง/เงื่อนไขของแผนก่อนตัดสินใจ |
| ต่อประกัน, ต่ออายุ, กรมธรรม์หมดเมื่อไร | ต่ออายุ | ขอประเภทประกัน วันหมดอายุ และเลขกรมธรรม์/ข้อมูลที่ไม่อ่อนไหวเท่าที่จำเป็น |
| เคลมยังไง, เกิดเหตุแล้วทำอะไร | สินไหม | ให้เก็บหลักฐาน แจ้งบริษัทโดยเร็ว และไม่รับปากผลเคลมแทนบริษัท |

## 2. รถยนต์และ พ.ร.บ.

**คีย์เวิร์ด:** ชั้น 1, ชั้นหนึ่ง, ชั้น 2+, สองพลัส, ชั้น 3+, สามพลัส, ชั้น 3, ซ่อมห้าง, ซ่อมศูนย์, ซ่อมอู่, รถชน, คู่กรณี, ชนเอง, ชนเสา, หินดีด, รถหาย, ไฟไหม้, น้ำท่วม, พ.ร.บ., พรบ, เคลม, excess, deductible, ระบุชื่อผู้ขับ, NCD, ส่วนลดประวัติดี, ต่ออายุ

- **ชั้น 1:** เหมาะเมื่อกังวลความเสียหายรถตนเองแม้ไม่มีคู่กรณี รวมถึงภัยหลักตามเงื่อนไขแผน
- **2+ / 3+:** รถตนเองคุ้มครองเมื่อชนยานพาหนะทางบกและมีคู่กรณีตามเงื่อนไข; 2+ อาจรวมรถหาย/ไฟไหม้/น้ำท่วม ส่วน 3+ โดยทั่วไปไม่รวม จึงต้องดูแผนจริง
- **พ.ร.บ.:** คุ้มครองคนจากอุบัติเหตุรถ ไม่ใช่ค่าซ่อมรถ และเป็นคนละส่วนกับประกันภาคสมัครใจ
- **คำถามต่อที่ควรถาม:** รถยี่ห้อ รุ่น ปีใช้งาน, งบต่อปี, ต้องการซ่อมห้างหรืออู่, ความกังวลเรื่องน้ำท่วม/รถหาย และมีประกันเดิมหรือไม่

## 3. บ้าน อัคคีภัย และทรัพย์สิน

**คีย์เวิร์ด:** ประกันบ้าน, อัคคีภัย, ไฟไหม้บ้าน, น้ำท่วมบ้าน, แผ่นดินไหว, โจรกรรม, ทรัพย์สินภายใน, คอนโด, อาคาร, โรงงาน, สต๊อก, IAR, ทุนประกัน, under-insurance, average clause

- แยก **มูลค่าสิ่งปลูกสร้าง** ออกจากที่ดินและทรัพย์สินภายในก่อนตั้งทุน
- ถามความเสี่ยงเสริม เช่น น้ำท่วม ลมพายุ โจรกรรม และลักษณะการใช้งาน (อยู่อาศัย/ให้เช่า/ธุรกิจ)
- แจ้งว่าภัยธรรมชาติ วงเงินย่อย และข้อยกเว้นแตกต่างกันตามกรมธรรม์; ไม่กล่าวว่าคุ้มครองครบทุกภัยโดยไม่ตรวจแผน

## 4. อุบัติเหตุส่วนบุคคล (PA) และประกันกลุ่ม

**คีย์เวิร์ด PA:** PA, อุบัติเหตุส่วนบุคคล, ค่ารักษา, ชดเชยรายได้, ทุพพลภาพ, เสียชีวิต, ขี่มอเตอร์ไซค์, อาชีพเสี่ยง

**คีย์เวิร์ดกลุ่ม:** ประกันกลุ่ม, สวัสดิการพนักงาน, HR, บริษัท, พนักงาน, employee benefits, ประกันสุขภาพกลุ่ม, ประกันชีวิตกลุ่ม

- **PA** คุ้มครองอุบัติเหตุ ไม่ใช่การเจ็บป่วยทั่วไป; ต้องถามอาชีพ ทุนที่ต้องการ ค่ารักษา และการใช้รถจักรยานยนต์ เพราะเงื่อนไขแตกต่างตามแผน
- **ประกันกลุ่ม** เหมาะกับนายจ้าง/HR ที่ต้องการสวัสดิการชีวิต สุขภาพ หรือ PA; เก็บจำนวนพนักงาน อายุเฉลี่ย สถานที่ทำงาน และสวัสดิการเดิมเพื่อขอใบเสนอราคา

## 5. ขนส่งทางทะเล ความรับผิด และวิศวกรรม

| ประเภท | คีย์เวิร์ดที่พบบ่อย | ข้อมูลสำหรับเริ่มขอราคา |
|---|---|---|
| ขนส่งสินค้า/Marine Cargo | cargo, ขนส่ง, นำเข้า, ส่งออก, CIF, FOB, ICC, ตู้คอนเทนเนอร์ | ชนิดสินค้า มูลค่า เส้นทาง วิธีขนส่ง และ Incoterms |
| ความรับผิดต่อบุคคลภายนอก | public liability, ลูกค้าลื่นล้ม, ร้านค้า, โรงแรม, product liability | ประเภทธุรกิจ รายได้/ขนาดสถานที่ ประวัติการเคลม วงเงินที่ต้องการ |
| งานวิศวกรรม | CAR, EAR, เครื่องจักร, ก่อสร้าง, ติดตั้ง, EEI, boiler | ลักษณะโครงการ มูลค่างาน ระยะเวลาก่อสร้าง/ติดตั้ง สถานที่ และผู้รับเหมา |
| โจรกรรม | ประกันโจรกรรม, ร้านค้า, สต๊อกหาย | ประเภททรัพย์สิน มูลค่า ระบบกล้อง/รปภ. และสถานที่ตั้ง |

## 6. ประกันชีวิต

**คีย์เวิร์ด:** ประกันชีวิต, ตลอดชีพ, term, ชั่วระยะเวลา, สะสมทรัพย์, ออมเงิน, บำนาญ, เกษียณ, ลดหย่อนภาษี, unit linked, ยูนิตลิงก์

- จับคู่ความต้องการก่อนเลือกแบบ: คุ้มครองครอบครัว/หนี้สิน, ออมเงิน, เกษียณ หรือการลงทุน
- **Unit Linked** ต้องอธิบายว่าผลตอบแทนส่วนลงทุนไม่การันตีและมีความเสี่ยง; ห้ามนำเสนอเป็นเงินฝากหรือรับประกันผลตอบแทน
- ระบบมีข้อมูลตัวอย่างผลิตภัณฑ์ตลอดชีพเท่านั้น จึงต้องส่งต่อผู้เชี่ยวชาญเมื่อขอใบเสนอราคาชีวิต สุขภาพ หรือบำนาญ

## 7. หลักการตอบที่ต้องยึด

1. เริ่มจากเหตุการณ์/ความเสี่ยงของลูกค้า แล้วค่อยจับคู่ผลิตภัณฑ์
2. หากลูกค้าถามว่า “เคลมได้ไหม” ให้ระบุว่าเป็นคำอธิบายเบื้องต้น ผลสุดท้ายขึ้นกับกรมธรรม์ ข้อเท็จจริง และการพิจารณาของบริษัท
3. อย่าอ้างราคา บริษัท วงเงิน หรือสิทธิประโยชน์ที่ไม่อยู่ในผลค้นหาหรือเอกสารผลิตภัณฑ์
4. ก่อนขอข้อมูลส่วนบุคคล ให้ตอบคำถามและให้ข้อมูลที่ช่วยตัดสินใจก่อน; ขอข้อมูลติดต่อเฉพาะเมื่อลูกค้าต้องการใบเสนอราคา/ให้เจ้าหน้าที่ติดต่อกลับ
