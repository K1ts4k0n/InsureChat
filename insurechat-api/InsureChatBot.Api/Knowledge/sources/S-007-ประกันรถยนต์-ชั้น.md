# S-007 — ประกันรถยนต์ (ชั้น 1/2+/3+/2/3 + พ.ร.บ.)

> **ที่มา:** ประกันติดโล่, Chubb Samaggi, One2car, Lotus's Money Plus (ค้นเว็บ 1 มิ.ย. 2026)

## สาระสำคัญ
- **พ.ร.บ. (ภาคบังคับ):** คุ้มครอง "คน" (ผู้ประสบภัย) ตามกฎหมาย ไม่คุ้มตัวรถ/ทรัพย์สิน
- **ชั้น 1:** คุ้มครองครบสุด — รถเราเสียหายแม้ไม่มีคู่กรณี, รถหาย, ไฟไหม้, น้ำท่วม/ภัยธรรมชาติ, คู่กรณี
- **ชั้น 2+:** คุ้มรถเรา **เฉพาะกรณีชนกับยานพาหนะทางบก (มีคู่กรณี)** + รถหาย + ไฟไหม้ + น้ำท่วม + คู่กรณี
- **ชั้น 3+:** คล้าย 2+ แต่ **ไม่คุ้ม** รถหาย/ไฟไหม้/ภัยธรรมชาติ — คุ้มรถเราเฉพาะชนกับยานพาหนะ + คู่กรณี
- **ชั้น 2:** คุ้มคู่กรณี + รถหาย + ไฟไหม้ แต่ **ไม่คุ้มตัวรถเรา** จากการชน
- **ชั้น 3:** คุ้มเฉพาะคู่กรณี (บุคคลภายนอก) ไม่คุ้มรถเรา — เบี้ยถูกสุด

## ประเด็นใช้ขายได้จริง
- จับคู่ตามอายุ/มูลค่ารถ + พฤติกรรมขับ + งบ (ดู [[เปรียบเทียบแผน-จับคู่-need]])
- 2+ vs 3+: ต่างกันหลักที่ "รถหาย/ไฟไหม้/ภัยธรรมชาติ" (2+ คุ้ม, 3+ ไม่คุ้ม)
