# S-011 — คู่มือติวสอบความรู้เพื่อขอรับใบอนุญาต "นายหน้าประกันวินาศภัย"

> **ที่มา:** บริษัท ศรีกรุงโบรคเกอร์ จำกัด (เอกสารประกอบการติวสอบใบอนุญาตนายหน้าประกันวินาศภัย สนง.คปภ.)

## โครงสร้างเนื้อหาในคู่มือ
1. **จรรยาบรรณนายหน้าประกันวินาศภัย:** มาตรฐานจริยธรรม 6 ประการ, การปฏิบัติหน้าที่ต่อผู้เอาประกัน บริษัท และสังคม
2. **ประมวลกฎหมายแพ่งและพาณิชย์ว่าด้วยประกันภัย:** มาตรา 861-897 (สัญญาประกันภัย, ส่วนได้เสีย, โมฆะ/โมฆียะ, การบอกล้าง, สิทธิหน้าที่, อายุความ 2 ปี)
3. **พ.ร.บ. ประกันวินาศภัย พ.ศ. 2535 (แก้ไขเพิ่มเติม ฉบับที่ 2 พ.ศ. 2551):** อำนาจนายทะเบียน, บทบาทตัวแทน vs นายหน้า, การรับเบี้ย, กองทุนประกันวินาศภัย (คุ้มครองสูงสุด 1 ล้านบาท)
4. **หลักประกันวินาศภัย:** ความเสี่ยง (Risk), ภัย (Peril), สภาวะภัย (Hazard: Physical, Moral, Morale), 6 หลักสำคัญของสัญญาประกันภัย
5. **ประกันภัยรถยนต์:** พ.ร.บ. คุ้มครองผู้ประสบภัยจากรถ พ.ศ. 2535 (ค่าเสียหายเบื้องต้น vs ส่วนเกิน), กองทุนทดแทนผู้ประสบภัย, ภาคสมัครใจ ชั้น 1/2+/3+/2/3, ตารางความคุ้มครอง, ความเสียหายส่วนแรก (Deductible/Excess), ข้อยกเว้นแอลกอฮอล์ (50 mg%), ส่วนลดประวัติดี (20-50%), ส่วนลดระบุชื่อคนขับ (5-20%)
6. **ประกันอัคคีภัยและทรัพย์สิน:** 3 ภัยมาตรฐาน, 4 ภัยธรรมชาติบ้านอยู่อาศัย, สิ่งปลูกสร้าง 3 ชั้น, การประกันภัยต่ำกว่ามูลค่าและหลักเฉลี่ย (Average Condition)
7. **ประกันภัยทางทะเลและขนส่ง:** กรมธรรม์ตัวเรือ (Time/Voyage), P&I Club, Incoterms, Institute Cargo Clauses (A/B/C)
8. **ประกันภัยเบ็ดเตล็ด:** PA (อบ.1 vs อบ.2, ชั้นอาชีพ 1-4), โจรกรรม (จร.1/2/3), งานวิศวกรรม (CAR, EAR, EEI, MB, Boiler), ความรับผิดตามกฎหมาย (Public Liability, Professional, D&O)
