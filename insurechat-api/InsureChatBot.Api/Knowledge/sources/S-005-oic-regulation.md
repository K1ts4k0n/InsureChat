# S-005 — คปภ. / พ.ร.บ. ประกันชีวิต

> **ที่มา:** สำนักงาน คปภ. (OIC) — พ.ร.บ.ประกันชีวิต พ.ศ.2535 และประกาศหลักเกณฑ์การเสนอขาย (ค้นเว็บ 1 มิ.ย. 2026)

## สาระสำคัญ
- คปภ. กำกับการประกอบธุรกิจและการเสนอขายของตัวแทน/นายหน้า
- ต้องมี **ใบอนุญาต** จึงเสนอขายได้
- มีประกาศ คปภ. เรื่องหลักเกณฑ์/วิธีการเสนอขาย และการปฏิบัติหน้าที่ของตัวแทน-นายหน้า
- กรอบหลัก: ห้ามให้ข้อมูลเท็จ/เกินจริง, ห้าม mis-selling, ต้องเปิดเผยตามจริง

## ประเด็นใช้ขายได้จริง
- เป็น guardrail ของทุกบทขายและข้อเสนอในวิกินี้
