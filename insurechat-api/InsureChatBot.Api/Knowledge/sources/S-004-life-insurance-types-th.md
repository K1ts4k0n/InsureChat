# S-004 — ประเภทประกันชีวิต (แหล่งไทย)

> **ที่มา:** ตลาดหลักทรัพย์ฯ (SET), AIA, Tokio Marine, Noon Blog (ค้นเว็บ 1 มิ.ย. 2026)

## สาระสำคัญ
- ประกันชีวิต 4 แบบหลัก: **ตลอดชีพ, ชั่วระยะเวลา, สะสมทรัพย์, บำนาญ**
- **ตลอดชีพ:** ทำง่าย เบี้ยไม่สูง ยืดหยุ่น มีมูลค่าเวนคืน คุ้มครองยาว
- **สะสมทรัพย์ vs ตลอดชีพ:** ใช้ลดหย่อนภาษีได้ทั้งคู่ ต่างกันที่เงินคืน/ระยะคุ้มครอง
- **Unit Linked:** เครื่องมือวางแผนการเงินระยะยาว ยืดหยุ่นสูง มีส่วนลงทุน — ผลตอบแทน "ไม่การันตี"

## ประเด็นใช้ขายได้จริง
- จับคู่ "แบบประกัน" กับ "Need" ของลูกค้า ไม่ขายแบบเดียวกับทุกคน
- ลดหย่อนภาษีเป็น hook ที่ดีกับมนุษย์เงินเดือน
