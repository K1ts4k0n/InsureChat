## สาระสำคัญ
- **T Broker** = โบรกเกอร์ในกลุ่ม **ธนชาต & MBK Group** เปิดรับสมัครนายหน้า/ตัวแทนทั่วประเทศ (ไม่ต้องมีบัตรนายหน้า/คนค้ำก็สมัครได้ สร้างทีม MLM ได้)
- เป็น **พอร์ทัลปฏิบัติการ** ของนายหน้า: คำนวณเบี้ย/คอม, ค้นหาผลิตภัณฑ์, แจ้งงาน, ต่ออายุ, ตรวจสถานะกรมธรรม์, Training
- **พาร์ทเนอร์บริษัทประกัน:** ธนชาตประกันภัย, ทิพยประกันภัย, เมืองไทยประกันภัย, กรุงเทพประกันภัย, นวกิจประกันภัย + ทีไลฟ์ประกันชีวิต
