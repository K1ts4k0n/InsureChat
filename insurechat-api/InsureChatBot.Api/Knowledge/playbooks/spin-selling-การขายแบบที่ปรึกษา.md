# SPIN Selling — ขายโดยให้ลูกค้าค้นพบความต้องการของตัวเอง

หัวใจ: **ฟังมากกว่าพูด** ใช้ "คำถาม" นำลูกค้าให้สรุปเองว่าเขาจำเป็นต้องมีประกัน — ไม่ใช่การยัดเยียดสินค้า เหมาะมากกับประกันชีวิตเพราะแตะ "อารมณ์/ความห่วงใย" มากกว่าเหตุผลล้วน (ที่มา: [[S-002]])

## 4 ชนิดคำถาม (ถามตามลำดับ)

| ขั้น | ชนิดคำถาม | เป้าหมาย | ตัวอย่างคำถามประกัน |
|------|-----------|----------|---------------------|
| **S** | Situation (สถานการณ์) | เก็บข้อมูลพื้นฐาน | "ตอนนี้คุณดูแลใครอยู่บ้างครับ มีภาระผ่อนอะไรไหม" |
| **P** | Problem (ปัญหา) | ขุด pain point | "ถ้าวันหนึ่งคุณทำงานไม่ได้ ใครจะรับภาระตรงนี้ต่อ" |
| **I** | Implication (ผลกระทบ) | ขยายความรุนแรง สร้าง urgency | "ถ้าค่าผ่อนบ้านยังเหลืออีก 15 ปี ครอบครัวจะอยู่ยังไงถ้าขาดรายได้คุณ" |
| **N** | Need-Payoff (ทางออก) | ให้ลูกค้าพูดประโยชน์เอง | "ถ้ามีเงินก้อนมาปิดหนี้และดูแลลูกได้ จะช่วยให้คุณสบายใจขึ้นไหม" |

> เคล็ด: **Implication คือขั้นที่ทรงพลังที่สุด** — ยิ่งลูกค้าเห็นผลกระทบชัด ความจำเป็นยิ่งสูง โดยที่เรายังไม่ต้องเสนอราคา

## เชื่อมเข้าสู่ขั้นตอนถัดไป
1. SPIN ขุด Need → 2. จับคู่ [[ประเภทประกันชีวิต]]/[[products/]] ให้ตรง Need → 3. เจอข้อโต้แย้ง ใช้ [[รับมือข้อโต้แย้ง-laarc-feel-felt-found]] → 4. [[เทคนิคปิดการขาย]]

## ใช้กับหน้า client
บันทึก S/P/I/N ที่ค้นพบลงหน้า [[clients/]] ของแต่ละราย เพื่อให้ข้อเสนอและการติดตามตรงจุด

## หลักคิด
- "ขายโดยไม่ขาย" — ช่วยลูกค้าคิด ไม่ใช่ปิดการขายด้วยการกดดัน
- ยึดจรรยาบรรณ [[คปภ-การกำกับและจรรยาบรรณตัวแทน]] — Need ต้องจริง ไม่ปั้นปัญหาเกินจริง
