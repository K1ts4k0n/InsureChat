# รับมือข้อโต้แย้ง (Objection Handling)

**ข้อโต้แย้ง = สัญญาณว่าลูกค้ากำลังสนใจ** เพียงแต่ต้องการให้เราช่วยต่อจุด อย่ารีบสวนกลับทันที — ฟังให้จบก่อน (ที่มา: [[S-001]], [[S-003]])

## กรอบหลัก: LAARC
| ขั้น | ทำอะไร |
|------|--------|
| **L**isten | ฟังอย่างตั้งใจ ให้พูดจบ |
| **A**cknowledge | แสดงความเข้าใจ ("ผมเข้าใจเลยครับ") |
| **A**sk | ถามเจาะให้ชัด ("ที่ว่าแพง คือเทียบกับอะไรครับ") |
| **R**espond | ตอบตรงประเด็นด้วยข้อมูล/เรื่องเล่า |
| **C**onfirm | ยืนยันว่าคลายกังวลแล้ว ("แบบนี้สบายใจขึ้นไหมครับ") |

## เทคนิคเสริม: Feel-Felt-Found
1. **Feel** — "ผมเข้าใจความรู้สึกคุณครับ"
2. **Felt** — "ลูกค้าหลายท่านก็เคยรู้สึกแบบนี้"
3. **Found** — "แต่พวกเขาพบว่า... (ประโยชน์จริงที่ได้รับ)"

## คลังข้อโต้แย้งที่เจอบ่อย + วิธีรับมือ

| ข้อโต้แย้ง | แก่นปัญหาจริง | วิธีรับมือ |
|-----------|----------------|-----------|
| **"เบี้ยแพง"** | มองเป็นค่าใช้จ่าย | **Anchor ราคา** กับสิ่งที่จ่ายอยู่แล้ว เช่น ค่ากาแฟ/ค่าสตรีมมิ่ง/มื้ออาหาร แล้วเปลี่ยนมุมเป็น "การลงทุนเพื่อความมั่นคง" (ดู [[เทคนิคปิดการขาย]]) |
| **"ขอคิดดูก่อน"** | ม่านบัง (smokescreen) ปกปิดเหตุผลจริง | ถาม: *"ที่บอกว่าขอคิดดู คือยังติดใจตรงไหนเป็นพิเศษไหมครับ"* แล้ว isolate ข้อโต้แย้งจริง ยืนยันว่าไม่มีประเด็นอื่น แล้วขอ commitment ไปต่อ |
| **"มีประกันอยู่แล้ว"** | ไม่แน่ใจว่าพอไหม | ถามทวน Need ([[spin-selling-การขายแบบที่ปรึกษา]]) ว่าความคุ้มครองครอบคลุมภาระปัจจุบันหรือยัง |
| **"ขอปรึกษาครอบครัวก่อน"** | ไม่ได้ตัดสินใจคนเดียว / เลื่อน | เสนอช่วยสรุปข้อมูลให้พาไปคุยที่บ้าน + นัดวันตามต่อชัดเจน |
| **"ไม่มีเงิน"** | งบ/ลำดับความสำคัญ | เสนอแบบ/ทุนที่พอจ่าย เริ่มเล็กก่อนได้ ([[ประเภทประกันชีวิต|Term]] เบี้ยถูก) |

## หลักคิด
- ฟังมากกว่าพูด เตรียมคำตอบที่ "rational + relatable"
- **"No" มักแปลว่า "Not yet"** — ลูกค้าต้องการความเข้าใจและความมั่นใจจากเรา
- **front-load**: เล่าเรื่อง/ตั้งคำถามดักข้อโต้แย้งที่พบบ่อยตั้งแต่ต้น จะลดข้อโต้แย้งช่วงปิด
- ยึดจรรยาบรรณ [[คปภ-การกำกับและจรรยาบรรณตัวแทน]] — รับมือด้วยข้อเท็จจริง ไม่กดดันด้วยความกลัว
